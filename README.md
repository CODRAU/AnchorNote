# Browser Annotator

A Chrome extension that allows users to highlight and annotate text on any webpage.

## Features

- Highlight text
- Add annotations
- Persist notes across sessions
- View annotations per page

## Tech Stack

- Chrome Extension (Manifest V3)
- JavaScript
- Chrome Storage API

## Development

Load the extension locally:

1. Open Chrome
2. Go to chrome://extensions
3. Enable Developer Mode
4. Click "Load unpacked"
5. Select this folder
